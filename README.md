I'm **Yaşar**. I build under the name **veax**, on my own, from Istanbul.

Right now that means a Chromium browser and a platform for building a link-in-bio
page — plus the desktop utilities and developer tools I release along the way.

**[veax.tr](https://veax.tr)** &nbsp;·&nbsp; [contact@veax.tr](mailto:contact@veax.tr)

## Released

| | | |

## How I work

**Sensible optimisation.** I don't claim the fastest software on the market. I claim
decisions that make sense, in the places you actually feel them.

**Nothing to relearn.** The browser is Chromium-based, so your Chrome extensions keep
working. The tools sit in the tray and stay out of the way.

**Shipped in the open.** The utilities are public here, readable and free to download.
Bug reports welcome.
